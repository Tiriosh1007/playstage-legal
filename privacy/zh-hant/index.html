私隱政策

最後更新：2026年9月30日

這份說明跟 PlayStage 現時的做法一致，包括只留在電話裡的市集，並寫明哪些 Firebase 安排仍未啟用。App 是給家長使用，可以儲存家庭和兒童資料。正式用來上架 App Store 之前，值得再做一次法律檢視。這份文件不是正式法律意見。

收集個人資料聲明

本聲明配合香港《個人資料（私隱）條例》。它適用於你在現時的本機 app 輸入個人資料的時候。

  • 電郵、顯示名稱和密碼是在電話上保留帳戶所必需。不提供就不能登入。要按某位小朋友的年齡給建議，就必須提供該小朋友的姓名和出生日期。性別、筆記、自訂活動和材料照片都是自願提供。
  • 收集目的見第 3 節。
  • 現時資料留在電話裡。同一部電話上的家庭成員，按角色看到獲准看到的內容。如果你把活動分享到本機市集，同一部電話上的其他帳戶可以閱讀該市集版本。我們不會把資料交給其他機構。日後若啟用 Firebase，Google 會按第 5 及第 9 節處理。
  • 你有權要求查閱和改正個人資料，見第 11 節。查閱或改正的要求會在 40 日內回覆。
  • 請把要求寄到 playstage.support@gmail.com。本頁不公布營運者姓名或郵寄地址。

1. 誰營運 PlayStage

PlayStage 由營運者獨立營運。本政策所說的「我們」是指 PlayStage 的營運者。本頁不公布營運者姓名。

聯絡：playstage.support@gmail.com。

2. PlayStage 收集甚麼資料

現時這個版本把資料存在你安裝 app 的那部電話。你提供的資料包括：

  • 帳戶：電郵地址、顯示名稱、密碼。
  • 家庭：家庭名稱、成員、角色（擁有者、家長、照顧者或只可查看），以及在該部電話產生的邀請碼。
  • 小朋友檔案：姓名、出生日期、可選的性別、可選的發展關注。App 裡的階段圖是隨程式附帶的圖，不是小朋友的相片。
  • 你儲存的玩樂紀錄、我的最愛、完成記錄、家長筆記和每週安排。
  • 每日日程：名稱、時間、星期、負責人、是否開啟提醒、該日有沒有標記完成。
  • 你撰寫的家庭活動：標題、年齡階段、可選的發展重點、時長、物料說明、步驟、可以說的話，以及安全提示。
  • 可選的材料照片，對象是玩具、書或其他用具，每項活動最多四張。這不是小朋友日記。
  • 如果你把家庭活動分享到這部電話上的市集：活動文字、你的顯示名稱，以及你標記放入市集的相片。相片預設不放入，除非你為該張相片開啟。
  • 語言選擇，存在電話裡。

性別、相片、筆記和自訂活動都可以不填。沒有電郵和密碼就不能保留本機帳戶。沒有小朋友的姓名和出生日期，就不能按該小朋友的年齡給建議。

PlayStage 不會要求小朋友自己建立帳戶。帳戶持有人是家長或照顧者。

3. 為何收集

  • 讓你在該部電話登入，並向家人顯示你的名稱。
  • 在同一部電話上保存家庭、角色和邀請碼，讓家人可以共用一個小朋友和一本日曆。
  • 按小朋友的年齡顯示官方遊戲建議。首頁每週五個建議只用官方活動。
  • 保存你選擇留下的玩樂時刻、筆記、日程和家庭活動。
  • 為已登入、而且負責該項日程的人，在這部電話安排提醒。
  • 在所屬活動中顯示材料照片。

我們不出售個人資料，不用來做廣告，也不用來替小朋友評分或做診斷。

4. 資料如何使用

資料用來運作你打開的功能：登入、同一部裝置上的家庭共用、遊戲庫、日曆、每日日程、提醒和家庭活動。只可查看的成員可以閱讀家庭共用的內容，不能修改。

日程提醒由電話自己的通知系統安排。通知內文不包含任何人的姓名。PlayStage 不會透過 Apple 推送通知或 Firebase Cloud Messaging，把這項提醒發送到另一部電話。

官方遊戲文字、階段指南、溝通技巧和理論卡片隨 app 附帶，不是向你收集的資料。

5. Firebase 與 Google Cloud

現時這個版本不會把帳戶、家庭檔案、小朋友檔案、玩樂紀錄、日程或相片傳送到 Firebase。App 沒有初始化 Firebase，程式裡的專案設定仍是佔位字。

日後的跨電話家庭版本計劃使用 Google Firebase：

  • Firebase Authentication：電郵和密碼登入，以及重設密碼。
  • Cloud Firestore：家庭、小朋友、日曆、日程和活動紀錄。
  • Cloud Storage：只供該家庭查看的材料照片。
  • Firebase App Check 和安全規則：避免一個已登入的人打開另一個家庭的資料。
  • 日後可能使用 Firebase Crashlytics 做崩潰報告。報告不得包含小朋友姓名。

該版本尚未推出。在本頁寫明已經啟用之前，請視作家人資料仍留在電話裡。啟用之後，Google 會按其條款處理 Firebase 資料。啟用前我們會先更新本政策。

6. 資料存放位置

今日，第 2 節的資料留在裝置上。沒有 PlayStage 伺服器，所以也沒有伺服器副本。

家庭共用版本推出時，Firestore 的家庭資料和 Cloud Storage 的相片計劃存放在 Google Cloud 香港區域（asia-east2）。登入資料由 Firebase Authentication 處理，Google 可能在其自身的基礎設施處理，而不限於香港。專案真正建立後，本頁會寫上實際區域。

7. 帳戶與登入資料

在現時的本機版本，電郵、顯示名稱和密碼存在 app 的本機儲存，讓電話可以再次登入。密碼存在這部裝置，是這個原型的做法。這不是正式產品的密碼儲存方式，也不會傳送給我們。

這個版本的重設密碼不會寄出電郵，因為沒有連接電郵服務。

計劃中的雲端版本不會把密碼放在 app 自己的資料庫。密碼由 Firebase Authentication 處理，重設信由該服務寄出。請不要把密碼寄到支援電郵。

8. 裝置與診斷資料

現時的 app 沒有崩潰報告或分析套件，也不會出現廣告追蹤的許可對話框。電話系統本身仍可能保留它自己的記錄，那不屬於 PlayStage。

如果日後加入 Crashlytics，它可能收到裝置、app 版本和崩潰追蹤。它不得收到小朋友姓名、寫有人名的日程標題，或材料照片的內容。該套件啟用時會更新本政策。

本機通知需要電話的通知許可。相機和相片圖庫只在你選取玩具、書或其他材料的圖片時使用。

9. 會否向第三者提供資料

現時這個版本不會把你的個人資料轉移給其他機構。同一部電話上的家庭成員，按角色看到獲准看到的內容。如果你把家庭活動分享到市集，同一部電話上的其他帳戶可以閱讀該市集版本，並下載一份到自己的家庭資料庫。這個市集存在電話裡。其他電話上的帳戶看不到。市集版本包含活動文字和你的顯示名稱。材料照片只有在你為該張相片標記放入市集時才會包含。該選項在你開啟之前是關閉的。

Firebase 啟用後，Google 會以基礎設施提供者的身分處理第 5 節所述資料。我們不授權 Google 把這些資料用於它自己的廣告。我們不出售資料，也不會交給資料經紀。

如果香港法律要求，或為了確立或抗辯法律申索，我們可能披露資料。Apple 按它自己的條款發行 iOS app，並處理 App Store 的下載。我們不會把家庭紀錄交給 Apple。

這幾頁法律頁面放在 GitHub Pages。打開它們不會把你的 PlayStage 帳戶傳給 GitHub。GitHub 會按其條款保留瀏覽這個網站的一般網站記錄。

10. 資料保留多久

本機資料會一直保留，直到你在「檔案」重設本機示範資料，或刪除 app。我們沒有另一份副本可以刪，因為我們沒有持有副本。

邀請碼、玩樂紀錄、日程和相片會跟該部電話上的家庭資料一起保留，直到有權刪除的成員刪除它們，或直到本機資料被重設。另一個家庭若已在這部電話下載了副本，該副本會留在他們的資料庫，直到他們刪除或重設這部電話，即使你其後從市集移除自己的項目。

計劃中的雲端版本會把家庭資料保留到你刪除帳戶或家庭為止，見第 12 節。今日沒有雲端備份在運行。如果日後開啟每週備份，計劃是保留 30 日然後刪除。備份開始時會在本頁說明。

11. 如何要求查閱或改正

家庭、小朋友、日程和活動的大部分欄位，都可以在 app 內查看和修改。

你也可以電郵 playstage.support@gmail.com，查問持有哪些個人資料，或要求改正。按《個人資料（私隱）條例》，查閱或改正資料的要求會在 40 日內回覆。放出資料前，我們可能請你確認自己是帳戶持有人。

因為現時的版本不會上載資料，我們能說明的是本政策列出的資料類別。紀錄本身在你的電話裡。

12. 如何刪除帳戶或資料

現時的版本：打開「檔案」，選擇「重設本機示範資料」。這會清除這部電話上的帳戶、家庭、小朋友、玩樂紀錄、我的最愛、筆記、每週安排、家庭活動、這部電話上的市集項目、材料照片、每日日程，以及登入狀態。語言選擇會保留。若要移除 app 的檔案，再刪除 app。只存在該部電話的相片會隨 app 的儲存空間一併移除。

目前沒有雲端帳戶可以刪。電郵給我們不能刪除一份我們沒有持有的副本，也不能刪除別人電話上的資料，因為這個版本不會同步。

計劃中的雲端版本：刪除帳戶會在 app 內進行，而不是只靠電郵。一個家庭的最後一位擁有者，要先指定另一位擁有者，或刪除該家庭，包括小朋友檔案、紀錄、活動和相片，然後才移除登入帳戶。該功能存在時會更新本節。

13. 兒童與家庭資料

PlayStage 給家長和照顧者使用。它不是以兒童為對象，也不放在兒童應用程式類別。不應要求小朋友自行建立帳戶。

家長或照顧者加入小朋友檔案時，提供的是該小朋友的姓名、出生日期，以及可選的性別或關注項目。請只加入你負責的小朋友。

現時產品的預設私隱做法：

  • 性別、相片、筆記和自訂活動都是可選。
  • 材料照片不會放入市集項目，除非你為該張相片標記。市集只供這部電話上的帳戶使用。沒有放在互聯網上的市集，其他電話也看不到。
  • 提醒不會寫出小朋友或照顧者的姓名。
  • 每週官方建議維持隨 app 附帶的活動。自訂活動不會取代它們。
  • 只可查看的成員不能修改家庭紀錄。

請不要在材料照片中拍到小朋友的臉、姓名或聯絡方法。App 有文字提示，但不會掃描相片來強制執行。

14. 保安

本機資料靠電話的鎖定和作業系統的 app 儲存來保護。原型的密碼儲存不是正式產品的保安水平。請不要使用你的電郵或銀行密碼。

程式庫裡的雲端資料庫規則草稿沒有部署，也不可以按現稿部署。按現稿，已登入的人可以把自己加入一個家庭，邀請碼也可以被過於廣泛地讀取。雲端版本在規則重寫並測試之前不會推出。測試要證明一個家庭不能讀取另一個家庭，只可查看的成員不能寫入。

沒有一種儲存方式是絕對安全的。請鎖好電話，不要在公開場合分享邀請碼。

15. 不是醫療服務

PlayStage 只提供資料和安排上的功能。它不提供醫學診斷、治療或專業醫療意見。

年齡階段、遊戲建議、溝通例子和理論卡片是一般教育資料。它們不是對任何小朋友的評估，也不是病歷。如果你擔心懷孕、小朋友的健康或發展，請向合資格的醫護人員查詢。任何建議你都可以不用。

16. 本政策的更改

如果 app 開始把資料傳送到 Firebase、加入崩潰報告、開放其他電話也能看到的市集，或更換營運者，會先更新本頁，並更改上方日期。支援頁會使用同一個日期。該日期之後繼續使用雲端版本，即表示你已獲通知政策已更新。本機版本會繼續按本政策所述運作，直到有更新另行說明。
